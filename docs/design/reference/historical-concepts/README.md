# Earlier Breezze logo/icon explorations (archival)

These two *original* documents are retained solely to prevent loss of earlier design exploration:

- `GLASS_DISC_EXPORT_SPEC.md`: concepts A/B/C and Glass Disc recommendation. It references proposed per-mode SVGs and exports but **does not itself contain those SVG files**.
- `DRIFT_EXPORT_SPEC.md`: separate Concept C / The Drift icon-variant and lockup requirements, also a **specification rather than actual exported SVG files**.

These directions conflict in color, geometry and recommendation. **The active approved Breezze icon is the existing monochrome white custom mark on black**, not an inferred combination of Glass Disc and Drift concepts. Any future change requires selecting an actual supplied master SVG and verifying platform launcher exports. Don't copy these reference documents into the Flutter bundle.
