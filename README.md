# MetroMusic
**A sleek, Kotlin‑based music player inspired by Apple Music**  

![Screenshot](https://raw.githubusercontent.com/MetroKim/MetroMusic/main/assets/screenshots/app.png)

## ✨ Features
- 🎵 Playback of local audio files  
- 📀 Album art fetching from MusicBrainz  
- 🌙 Dark / Light theme (auto‑system)  
- ⏱️ Last‑fm scrobbling (optional)  

## 🚀 Getting started
```bash
# Clone the repo
git clone https://github.com/MetroKim/MetroMusic.git
cd MetroMusic

# Open in Android Studio
# (or build with Gradle)
./gradlew assembleDebug
```
