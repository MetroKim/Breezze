# Breezze
**A modern YouTube music client with clean aesthetics inspired from Apple Music**  
_Forked from [kushagrasinghx/BitChord](https://github.com/kushagrasinghx/BitChord)_

![Screenshot](https://raw.githubusercontent.com/MetroKim/Breezze/main/assets/screenshots/app.png)

## ✨ Features
- 🎶 Stream YouTube music in a music‑player UI  
- 📑 Playlist management (import/export)  
- 🌙 Dark / Light theme (auto‑system)  
- ⏱️ Last‑fm scrobbling (optional)  

## 🚀 Getting started
```bash
# Clone the repo
git clone https://github.com/MetroKim/Breezze.git
cd Breezze

# Open in Android Studio
# (or build with Gradle)
./gradlew assembleDebug
```
